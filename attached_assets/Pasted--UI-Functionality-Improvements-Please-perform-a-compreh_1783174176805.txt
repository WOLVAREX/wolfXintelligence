# UI & Functionality Improvements

Please perform a comprehensive update to the chat application with a strong focus on usability, responsiveness, and reliability.

## 1. Model Authorization

* I selected four AI models, but every prompt returns an **"Unauthorized"** error.
* Investigate the root cause.
* Ensure each selected model authenticates correctly and can generate responses.
* If a model is unavailable, display a clear user-friendly error instead of failing silently.

## 2. Reasoning Experience

Improve how reasoning is displayed.

Requirements:

* Responses should stream naturally.
* While the AI is reasoning, show a subtle reasoning section similar to Claude or Replit AI.
* Do **not** expose the complete chain of thought.
* Instead, display short, high-level progress updates such as:

  * Analyzing the request...
  * Planning the response...
  * Gathering relevant information...
  * Preparing the final answer...
* The reasoning area should appear in a collapsed, lightly styled container with a clean shadow effect.
* Once the final answer is ready, keep the reasoning collapsed by default.

## 3. Chat Interface Redesign

Redesign the entire chat layout.

Goals:

* Modern and professional appearance.
* Clean spacing and typography.
* Better message alignment.
* Smooth animations.
* Improved loading indicators.
* Better code block styling.
* Better markdown rendering.
* Better handling of long responses.
* Proper dark/light theme support.
* Overall UX comparable to ChatGPT, Claude, or Replit AI.

## 4. Automatic Preview Panel

When the AI generates content that can be previewed, automatically open a preview panel.

Examples:

* HTML
* React
* Next.js
* Vue
* Websites
* UI Components
* Dashboards
* Landing pages
* Documents
* Markdown pages

Requirements:

* Automatically detect previewable outputs.
* Open the preview without requiring the user to click anything.
* Allow users to switch easily between Chat and Preview.
* If preview generation fails, display a meaningful error message.

## 7. Overall Quality

This should feel like a polished production-ready AI application rather than a prototype.

Prioritize:

* Reliability
* Performance
* Responsiveness
* Modern UI/UX

Before implementing any changes, analyze the current codebase, identify the underlying issues, and then refactor the affected components instead of applying temporary fixes.
